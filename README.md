# Snake Remastered

A 2D Snake game developed independently using Unity and C#.

## About

Snake Remastered is a project I developed while learning and improving
my C# and Unity game-development skills.

This project represents my transition from learning programming concepts
to applying them in a complete, playable software project.

## Challenges

One of the biggest challenges I faced while developing Snake Remastered
was a bug involving the snake's head and body sprites. The sprites were
not behaving as I expected, and I initially struggled to identify the
cause of the problem.

Instead of repeatedly changing the code without a clear direction, I
stepped away from the computer, opened my notebook, and started breaking
the problem down on paper. I wrote down what I expected to happen,
what was actually happening, and traced the logic step by step.

This approach helped me identify the source of the bug and fix it.

More importantly, I learned a debugging habit that I still use today:
when a programming problem becomes difficult, I first write the problem
down, break it into smaller parts, and reason through it before changing
the code.

That experience changed the way I approach debugging and problem
solving.
